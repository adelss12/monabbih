# منبّه

تطبيق عربي لتنبيهك بقرب انتهاء الاشتراكات (Netflix وغيرها) والوثائق الرسمية (الجواز، الرخصة، الهوية، الاستمارة).

- يقبل إدخال التاريخ **ميلاديًا أو هجريًا** (تقويم أم القرى) ويعرض الاثنين: `12/ أكتوبر (10)/2026` و `1/ جمادى الأولى (5)/1448هـ`.
- **مزامنة بين أجهزتك** عبر Supabase بعد تسجيل الدخول.
- **تنبيه بالبريد الإلكتروني** يوميًا الساعة 8 صباحًا بتوقيت الرياض عبر GitHub Actions.

## مكونات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html`, `styles.css`, `js/app.js` | واجهة التطبيق (تُنشر على GitHub Pages) |
| `js/dates.js` | تحويل وتنسيق التواريخ الهجرية والميلادية |
| `js/config.js` | رابط Supabase والمفتاح العام |
| `supabase/schema.sql` | إنشاء جدول البيانات وحمايته |
| `scripts/send-reminders.mjs` | سكربت إرسال التنبيهات بالبريد |
| `.github/workflows/reminders.yml` | جدولة التنبيه اليومي |

## خطوات التشغيل (مرة واحدة)

### 1) قاعدة البيانات — Supabase (مجاني)
1. أنشئ حسابًا في <https://supabase.com> ثم **New project** (اختر أقرب منطقة، واحفظ كلمة مرور قاعدة البيانات).
2. من القائمة: **SQL Editor ← New query**، الصق محتوى `supabase/schema.sql` كاملًا واضغط **Run**.
3. من **Project Settings ← API** انسخ:
   - **Project URL**
   - **anon / public key** (للتطبيق)
   - **service_role key** (سرّي — لـ GitHub Secrets فقط)
4. من **Authentication ← URL Configuration** ضع في **Site URL**: `https://adelss12.github.io/monabbih/`

### 2) ربط التطبيق
عدّل الملف `js/config.js` وضع فيه **Project URL** و **anon key**.
> المفتاح العام آمن في الكود لأن كل مستخدم لا يرى إلا بياناته (RLS). **لا تضع service_role هنا أبدًا.**

### 3) نشر الموقع — GitHub Pages
**Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save**
بعد دقيقة يعمل على: `https://adelss12.github.io/monabbih/`

### 4) البريد — Resend (الأسهل، بدون تحقق بخطوتين)
1. سجّل في <https://resend.com> بنفس البريد الذي تستخدمه في منبّه.
2. **API Keys ← Create API Key** وانسخ المفتاح (يبدأ بـ `re_`) وضعه في السر `RESEND_API_KEY`.
> بدون نطاق خاص يرسل Resend فقط إلى البريد المسجّل فيه — مناسب للاستخدام الشخصي.

### 4-ب) بديل: كلمة مرور تطبيقات Gmail
1. فعّل **التحقق بخطوتين** في حساب Google.
2. ادخل <https://myaccount.google.com/apppasswords> وأنشئ كلمة مرور باسم `monabbih` (16 حرفًا).

### 5) الأسرار — GitHub Secrets
**Settings ← Secrets and variables ← Actions ← New repository secret** وأضف:

| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | المفتاح السري: `sb_secret_...` (أو service_role من تبويب Legacy) |
| `GMAIL_USER` | بريدك في Gmail الذي سيُرسل منه |
| `GMAIL_APP_PASSWORD` | كلمة مرور التطبيقات (16 حرفًا) |

### 6) التجربة
1. افتح الموقع، أنشئ حسابًا بنفس بريدك، أكّده من الرسالة، ثم سجّل الدخول.
2. أضف عنصرًا ينتهي خلال أيام.
3. **Actions ← تنبيهات الانتهاء بالبريد ← Run workflow** (مع تفعيل وضع الاختبار) — يجب أن يصلك البريد خلال دقيقة.
